# SEAT

Teacher-friendly classroom and exam seating arrangement app.

## Live App

https://seat-five.vercel.app

## Development

```bash
npm install
npm run dev
```

Open http://127.0.0.1:3000 or http://localhost:3000.

## Useful Commands

```bash
npm run typecheck
npm run build
```

## Deployment

This repository is connected to Vercel. Pushing to `main` triggers a production deployment.
